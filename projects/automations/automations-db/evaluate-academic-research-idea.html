Evaluate Academic Research Idea

Feb 07, 202613 min read

YOU MUST LOAD THIS FULL PAGE AND THE EVALUATION SCORING KIT BEFORE EXECUTING {color=“red_bg”}

### INPUT **Required:** A research idea. Can be any of the following: - A free-text description (topic, question, or rough concept) - A URL to an existing page in the Research Ideas DB - A meeting transcript or note containing a research idea to extract **Optional:** - Target research type (e.g., Literature Review, Experimental Study, Survey Study) - Target journal or venue - Depth flag: `quick` (skip literature search, score from input only) or `full` (default, includes academic source search) ### OBJECTIVE Evaluate an academic research idea using scientifically validated criteria to determine whether it is worth pursuing. Produce a structured evaluation with scored dimensions, evidence-based reasoning, and a clear verdict. Then document the idea (and its evaluation) in the database with all properties populated. **Grounding frameworks:** - **FINER Criteria** (Hulley et al., 2013): Feasible, Interesting, Novel, Ethical, Relevant - **NSF Merit Review**: Intellectual Merit + Broader Impacts - **Methodological soundness** principles from research design literature (Creswell & Creswell, 2018) - **Evidence taxonomy and debiasing** from Market Evaluation Scoring Kit ### STEPS **Phase 0: Setup and Idea Extraction** 1. If the input is a page URL, load the page and extract the research idea, any existing RQs, hypotheses, and abstract 2. If the input is free text, parse it into a structured idea summary 3. Restate the idea as a one-sentence **Problem Statement** and a preliminary **Research Question** (if the user hasn't already provided one) 4. **Check for Persona Context:** If this research idea is tied to a Project in , load the Project page and check for a `🎯 Persona Shortlist` section. Active personas provide validated target user profiles that inform Phase 2 scoring: **Interest** (practitioners who would care about findings), **Relevance** (practical applicability for specific user populations), and **Methodological Rigor** (grounding construct validity in real user characteristics). If no Project context, proceed without. 5. Identify the most likely **Research Type** from the DB schema options (Literature Review, Survey Study, Experimental Study, Case Study, Mixed Methods, Usability Study, Interview Study, Field Study, Other) **Phase 1: Literature Gap Analysis** *(skip if **`quick`** depth)* 1. Search the **Academic Source Registry** domains from the Master Prompt: - **Primary:** [scholar.google.com](http://scholar.google.com), [semanticscholar.org](http://semanticscholar.org), [arxiv.org](http://arxiv.org), [dl.acm.org](http://dl.acm.org), [openalex.org](http://openalex.org) - **Secondary (HCI/HF):** [ieee.org](http://ieee.org), [frontiersin.org](http://frontiersin.org), [dl.acm.org](http://dl.acm.org) (CHI/CSCW) - **Secondary (domain-conditional):** add sources based on the topic (psych, health, social science, etc.) 2. Run 2-3 parallel queries with different formulations to maximize coverage 3. Use `category: "research paper"` filter 4. From search results, identify: - **Existing work:** What has already been studied in this space? - **Gaps:** What questions remain unanswered or underexplored? - **Recency:** Is this topic actively being researched (papers in the last 2-3 years)? - **Methodological patterns:** What methods have been used? What methods are missing? 5. Summarize findings as a **Literature Landscape** brief (3-5 bullet points) **Phase 2: FINER+ Evaluation (Scored Dimensions)** Score each dimension 0-10 using the behavioral anchors below. Apply the **Evidence Type Taxonomy** from the Market Evaluation Scoring Kit to cap scores based on evidence tier. **Dimension 1: Feasibility (F)** *Can this research actually be conducted given realistic constraints?* - Methodological clarity: Is a clear research design available? - Data access: Can the required data be collected or accessed? - Skills and tools: Does the researcher have (or can acquire) the necessary expertise? - Timeline: Can this be completed within a reasonable academic timeframe? - Ethical approval: Are there IRB/ethics board concerns that could delay or block the study?
ScoreAnchor
**8-10**Clear methodology, data sources identified and accessible, required skills available, IRB pathway straightforward. Could begin data collection within 1-2 months.
**5-7**Methodology is plausible but needs refinement. Data access requires negotiation or instrument development. Some skill gaps are bridgeable. Timeline is 3-6 months to data collection.
**2-4**Significant methodological uncertainty. Data access is speculative. Requires skills or tools not currently available. IRB process is complex or uncertain.
**0-1**No viable methodology identified. Data is inaccessible. Required expertise is unavailable.
**Dimension 2: Interest (I)** *Will the scientific community and practitioners care about the findings?* - Does this address a question that researchers are actively debating? - Would the results change how practitioners work? - Is there a clear audience for this work (specific conference, journal, community)?
ScoreAnchor
**8-10**Topic appears in recent call-for-papers, keynotes, or special issues. Multiple research groups are working in adjacent areas. Practitioners have expressed need for this knowledge.
**5-7**Topic is relevant to an identifiable community. Some recent papers cite the need for this type of work. Moderate practitioner interest.
**2-4**Niche interest. Few researchers are working in this area. Unclear practitioner relevance.
**0-1**No identifiable audience. Topic appears abandoned or saturated.
**Dimension 3: Novelty (N)** *Does this contribute something genuinely new to the field?* - New theoretical contribution (framework, model, construct) - New empirical findings (population, context, variables) - New methodology or methodological application - Significant replication with meaningful extension
ScoreAnchor
**8-10**No existing study addresses this specific question in this context. Proposes a new construct, framework, or methodological approach. Literature gap is clearly documented.
**5-7**Extends existing work to a new population, context, or variable. Combines known methods in a new way. Incremental but meaningful advancement.
**2-4**Similar studies exist with minor differences. Contribution is primarily confirmatory without meaningful extension.
**0-1**This has been done. Direct replication without clear justification for why replication is needed.
**Dimension 4: Ethics (E)** *Can this research be conducted ethically and responsibly?* - Participant risk and burden - Data privacy and consent requirements - Potential for misuse of findings - Equity and inclusion considerations
ScoreAnchor
**8-10**Minimal participant risk. Standard consent procedures apply. No sensitive data. Inclusive design. No foreseeable misuse.
**5-7**Some ethical considerations that are manageable (e.g., workplace observation, survey on sensitive topics). Standard IRB protocol with conditions.
**2-4**Significant ethical concerns. Vulnerable populations, deceptive methods, or sensitive data requiring extensive safeguards.
**0-1**Ethically problematic. High participant risk, potential for harm, or irresolvable consent issues.
**Dimension 5: Relevance (R)** *Does this advance knowledge that matters beyond the study itself?* - Theoretical contribution to the field - Practical applicability for design, policy, or practice - Builds toward a larger research program - Timeliness (addresses a current need, not just academic curiosity)
ScoreAnchor
**8-10**Clear theoretical and practical implications. Results would directly inform design decisions, policy, or practice. Connects to an active research program. Timely.
**5-7**Contributes to theoretical understanding with indirect practical implications. Connects to broader themes but not a critical gap.
**2-4**Primarily academic exercise. Limited practical application. Tangential to current research priorities.
**0-1**No clear contribution to theory or practice.
**Dimension 6: Methodological Rigor (Bonus)** *How sound is the proposed (or likely) research design?* - Internal validity: Can causal or relational claims be supported? - External validity: Will findings generalize to relevant contexts? - Construct validity: Are the constructs well-defined and measurable? - Reliability: Can the study be replicated?
ScoreAnchor
**8-10**Well-defined constructs with validated measures. Appropriate design for the research question. Threats to validity are identified and mitigated. Clear analysis plan.
**5-7**Design is reasonable but has identifiable threats to validity. Some constructs need operationalization. Analysis approach is general but not fully specified.
**2-4**Significant validity concerns. Constructs are vague. Design may not support the claims the research question implies.
**0-1**No viable methodology. Fundamental mismatch between question and proposed approach.
**Phase 3: Pre-Mortem (Academic Version)** *Adapted from Klein (2007). Run AFTER scoring.* **Prompt:** *"It is two years from now. This research project failed to produce a publishable paper. What went wrong?"* Structure the response as: 1. **Most likely failure mode:** The single most probable reason (e.g., couldn't recruit enough participants, data was inconclusive, got scooped) 2. **Hidden dependency:** Something the project assumes will be true that may not be (e.g., access to a specific tool, cooperation from an organization, a certain effect size) 3. **Reviewer objection:** The most likely criticism a peer reviewer would raise about the methodology or framing If any pre-mortem finding directly contradicts a high-scoring dimension, flag it and consider adjusting the score downward. **Phase 4: Synthesis and Verdict** 1. Calculate the **FINER+ Score:** Weighted average of all 6 dimensions - F (Feasibility): **20%** weight - I (Interest): **15%** weight - N (Novelty): **25%** weight - E (Ethics): **10%** weight - R (Relevance): **20%** weight - M (Methodological Rigor): **10%** weight 2. Apply the **Verdict Matrix:**
Score RangeVerdictAction
**8.0-10.0**🟢 **Strong Pursue**Begin research planning immediately. Document in DB as "Ideated" and create a research plan.
**6.0-7.9**🟡 **Conditional Pursue**Promising but has specific weaknesses to address. Document in DB as "Ideated" with noted conditions.
**4.0-5.9**🟠 **Refine**Core idea has merit but needs significant reworking. Document in DB as "Ideated" with refinement notes.
**0.0-3.9**🔴 **Defer or Abandon**Fundamental issues. Document in DB as "Archived" with rationale.
1. Generate a **Validation Confidence Block** per the Evaluation Scoring Kit 2. Identify the **Top 3 Strengths** and **Top 3 Risks** 3. Recommend **Specific Next Steps** (e.g., "conduct a scoping review on X," "pilot test the survey instrument," "identify a dataset for secondary analysis") **Phase 5: Publishing Outlet Discovery** *Identify the best-fit venues for this research and collect critical submission information.* 1. Based on the research topic, type, and domain from Phase 0, search for relevant publishing outlets: - **Conferences:** Search for upcoming CFPs in the topic area (e.g., CHI, CSCW, DIS, HFES, UbiComp) using web search with queries like `"[topic] call for papers 2026 2027"` and `"[topic] conference submission deadline"` - **Journals:** Search for journals that publish in this area using web search targeting `dl.acm.org`, `springer.com`, `tandfonline.com`, `journals.sagepub.com`, `wiley.com`, and `ieee.org` - **Special Issues:** Search for active special issue CFPs related to the topic 2. For each identified venue (aim for 3-5 strong matches), collect: - **Name and Type** (Journal, Conference, Workshop, Magazine) - **Publisher** (ACM, IEEE, Springer, Elsevier, SAGE, etc.) - **Impact Factor** (if available) - **Open Access** status (Yes, Hybrid, No) - **Topics** covered (map to existing topic tags in the Journals & Venues DB) - **Next Deadline** (submission deadline, camera-ready date, or rolling review date) - **Formatting Notes** (page limits, template required, citation style, column format, anonymization requirements) - **Submission Requirements** (abstract requirements, supplementary materials, cover letter, author statement, data availability, pre-registration) - **Publication Steps** (step-by-step process from submission to publication: e.g., submit via portal → desk review → peer review → revision → camera-ready → publication) - **Review Timeline** (typical time from submission to first decision, and to final publication) - **Acceptance Rate** (approximate, if available) - **Submission Portal** URL 3. For each venue, create or update a page in the database with all collected properties 4. Rank the venues by fit, considering: - **Topic alignment** with the research idea - **Timeline feasibility** (can the research be completed before the deadline?) - **Prestige vs. acceptance probability** trade-off - **Open access** preference - **Audience match** (who reads this venue? practitioners, academics, or both?) 5. Produce a **Publishing Outlet Brief** with: - Ranked list of recommended venues with rationale - Key deadlines highlighted (sorted chronologically) - A suggested "submission strategy" (e.g., target Venue A first; if rejected, pivot to Venue B with these modifications) **Phase 6: Document in Research Ideas DB** 1. Create a new page in (or update an existing page if one was provided as input) 2. Set properties from the evaluation: - **Project Title:** The research idea title - **Status:** Per the Verdict Matrix ("Ideated" or "Archived") - **Research Question(s):** The refined RQ(s) from Phase 0 - **Hypothesis:** If a testable hypothesis was identified - **Abstract:** A concise summary of the idea (2-3 sentences) - **Research Type:** The identified type from Phase 0 - **Lead Researcher:** Set to Michael (Michael Oliver) - **Target Journal:** Link to the top-ranked venue(s) from Phase 5 (use the Journals & Venues DB page URLs created/updated in Phase 5) 3. Add the **full evaluation report** as page content, structured as: - Literature Landscape (if `full` depth) - FINER+ Scorecard (table with all dimensions, scores, and rationale) - Pre-Mortem findings - Verdict and Weighted Score - Validation Confidence block - Publishing Outlet Brief (ranked venues, key deadlines, submission strategy from Phase 5) - Strengths, Risks, and Next Steps ### RULES - **Always load the Market Evaluation Scoring Kit** before scoring. Apply the Evidence Type Taxonomy to cap scores. - **Use the Academic Source Registry** from the Master Prompt for all literature searches. Run parallel queries across primary + domain-conditional secondary sources. - **Do not inflate scores.** When in doubt, score conservatively. Academic research is hard. A score of 6 is a solid idea. - **Separate what you know from what you assume.** Always classify evidence tier for each dimension. - **Pre-mortem is mandatory.** Do not skip it, even if scores are high. Optimism bias is real. - **Never fabricate citations.** If you reference a paper, it must come from actual search results. - **Respect the DB schema.** Only set properties that exist in the Research Ideas data source. Do not attempt to create new properties. - **If an existing DB page was provided as input**, update it rather than creating a duplicate. - **The evaluation report goes in the page content**, not in the properties. Properties are for structured metadata only. - **Domain focus:** Unless stated otherwise, evaluate ideas through the lens of HCI, Human Factors, and adjacent fields (Cognitive Psychology, Computational Sociology, Information Science). ### OUTPUT 1. **Chat summary:** A concise verdict with the FINER+ score, top strengths, top risks, and recommended next steps 2. **Research Ideas DB page** created (or updated) with: - All applicable properties populated - Full evaluation report as page content 3. **Status:** Set per the Verdict Matrix ### QUICK START EXAMPLES - "Evaluate this idea: How do mental models of AI change after extended use in enterprise settings?" → Full evaluation, new DB page - "Evaluate quick" → Quick evaluation (no lit search), update existing DB page - "Evaluate the research ideas from my last meeting" → Extract ideas from meeting, evaluate each, create DB pages --- **Methodological sources:** - Hulley, S. B., Cummings, S. R., Browner, W. S., Grady, D. G., & Newman, T. B. (2013). *Designing Clinical Research* (4th ed.). Lippincott Williams & Wilkins. (FINER criteria) - Klein, G. (2007). Performing a project pre-mortem. *Harvard Business Review, 85*(9), 18-19. - Creswell, J. W., & Creswell, J. D. (2018). *Research Design: Qualitative, Quantitative, and Mixed Methods Approaches* (5th ed.). SAGE. - National Science Foundation. (2024). *Merit Review Criteria.* [nsf.gov](http://nsf.gov). - Farrugia, P., Petrisor, B. A., Farrokhyar, F., & Bhandari, M. (2010). Research questions, hypotheses and objectives. *Canadian Journal of Surgery, 53*(4), 278-281.
