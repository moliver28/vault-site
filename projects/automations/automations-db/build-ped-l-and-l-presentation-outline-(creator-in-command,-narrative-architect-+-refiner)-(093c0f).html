BINDING STATEMENT

Topology: Pipeline (4 stages, sequential handoffs)

### INPUT **Required:** - `topic`: The L&L session topic/title - Evidence base (academic + practical sources with session phase mapping) **Optional (auto-populated when chained from Research & Ground):** - `core_claim`: Refined core claim - `audience_persona`: Refined persona (with emotional register + language cues) - `academic_evidence`: Academic sources with phase mapping - `practical_evidence`: Industry examples with phase mapping - `inoculation_brief`: Objections with rebuttals and bridge statements - `nudge_goal`: Desired behavior change - `format`: Session format (talk / workshop / hybrid / discussion) - `means_inventory`: Presenter's teaching means - `research_page_url`: URL of research brief page - `ideation_page_url`: URL of ideation page **Standalone inputs:** - `duration`: Target duration in minutes (default: 30-45) - `output_format`: `outline` (default, structured for LLM slide tools) \| `notion_slides` (Notion Presentation Mode) ### OBJECTIVE Produce a **presentation-ready outline** structured for export to external LLM slide generation tools (e.g., Gamma, [Beautiful.ai](http://Beautiful.ai), or any LLM with slide generation). The outline must: 1. Follow the 5-phase Narrative Arc from the 🎤 PED Lunch & Learn Designer mode 2. Map every source to a specific slide/moment 3. Include speaker notes with presenter guidance 4. Pass multiple refinement perspectives before finalization 5. Be structured enough that another LLM can generate a complete slide deck from it without ambiguity --- ## 🔄 PIPELINE STAGES ### Stage 1: NARRATIVE ARCHITECTURE (Creator + Narrative Architect) **Goal:** Design the story structure before writing any content. 1. Load the 🎤 PED Lunch & Learn Designer mode page (narrative arc, persuasion architecture) 2. Load 🎭 Narrative Architect mode 3. Map all evidence (academic + practical) to the 5-phase narrative arc: **Phase 1: The Problem Frame (10-15% of time)** - Select the **opening hook**: the single most compelling data point, scenario, or question that makes the cost of the status quo visible - Map: which source provides the hook? Which practical example illustrates the cost? - Calibrate to persona's **emotional register** (if they're defensive, open with curiosity not challenge) **Phase 2: Academic Authority (20-25% of time)** - Sequence the academic evidence to build a logical argument - Place the **inoculation move** here: acknowledge the #1 likely objection, then dismantle with evidence - Use the presenter's **means inventory** to calibrate authority level (reference experience, not credentials) **Phase 3: The Reframe (20-25% of time)** - Design the **pivot statement** (the "but here's a better way" moment) - Introduce the **mental model** the audience should internalize - Create an **analogy or metaphor** grounded in PED domain language (use persona's **language cues**) - Suggest a **visual/diagram** that encodes the reframe **Phase 4: Tactical Translation (25-30% of time)** - Map peer-scale and household-name practical examples to this phase - Design the **PED-specific application** (how this applies to their sprint, their roadmap, their design review) - If `format = workshop` or `hybrid`: design an **interactive exercise** (3-5 min max) - If `format = talk`: design a **worked example or case walkthrough** **Phase 5: The One Thing (10-15% of time)** - Define the **single behavior change** (must be low-friction, immediately doable) - Write the **rationale** (one sentence connecting the behavior to the evidence) - If applicable, design a **leave-behind artifact** (template, checklist, one-pager) **Handoff → Stage 2:** Draft narrative structure with evidence mapping ### Stage 2: SLIDE-BY-SLIDE OUTLINE (Creator) **Goal:** Translate the narrative architecture into a structured, slide-level outline formatted for external LLM consumption. **For each slide, produce:** ```javascript ## Slide [N]: [Title] **Phase:** [1-5 | Transition] **Content Type:** [text | data/stat | visual/diagram | quote | exercise | discussion] **On-Slide Content:** - [Bullet 1: what appears on the slide — concise, visual-first] - [Bullet 2] - [Bullet 3 max — slides should not be text-heavy] **Visual/Diagram Suggestion:** [Description of the visual element, if any] **Source:** [APA citation or industry source mapped to this slide] **Speaker Notes:** - [Note 1: what the presenter says — conversational, evidence-forward] - [Note 2: transition to next point] - [Note 3: if applicable, the inoculation move or bridge statement] - [Note 4: persona-specific calibration note] **Presenter Cue:** [Tone guidance, e.g., "pause here", "this is the inoculation moment", "invite questions"] ``` **Slide count guidance by duration:** - 20 min session: 10-14 slides - 30 min session: 15-20 slides - 45 min session: 22-28 slides **Structure rules:** - First slide = title + subtitle (the core claim as a question or bold statement) - Last slide = "The One Thing" + leave-behind artifact reference - No slide should have more than 3 bullet points of on-slide text - Every 4-5 slides, include a "breathing" slide (visual, quote, or provocative question) - Transition slides between phases should make the narrative arc visible **Handoff → Stage 3:** Complete slide-by-slide outline ### Stage 3: MULTI-PERSPECTIVE REFINEMENT (Refiner) **Goal:** Stress-test the outline through 5 distinct refinement perspectives before finalization. **Load** 🪞 Refiner **mode and run the outline through each perspective sequentially. Score each 1-5.**
**Perspective****What It Checks****Failure Signals**
**🧠 ELM Compliance**Does the session open with peripheral cues (authority, visuals, compelling scenario) before shifting to central route (evidence, logic)? Is the transition smooth?Opening with data dumps. Asking audience to process complex arguments before attention is secured. No credibility establishment before evidence.
**🎭 Audience Empathy**Does every slide pass the test: "Would the persona find this useful, clear, and non-threatening?" Is complexity calibrated to the persona's knowledge level? Does the language match their domain?Research jargon without translation. Assumptions about what the audience already knows. Talking down to experts or over novices. Using "you should" language instead of "here's what the evidence shows."
**🛡️ Inoculation Completeness**Are all identified objections preemptively addressed? Are they addressed *before* the audience would raise them (not after)? Are rebuttals evidence-based, not dismissive?Ignoring the #1 objection. Addressing objections too late (after the audience has already internally committed to the counterargument). Straw-manning objections. Dismissing concerns without evidence.
**📐 Scaffolding Coherence**Does knowledge build progressively (simple → complex)? Is each slide within the audience's ZPD given what came before? Could the audience follow this without backtracking?Introducing advanced concepts before foundations are laid. Assuming knowledge that wasn't established earlier in the session. Jumping between abstraction levels without bridging.
**🎬 Narrative Arc Integrity**Does the session have a clear through-line from Problem Frame to The One Thing? Does each phase transition feel natural? Does the ending land with impact?Sections that feel disconnected. Missing transitions between phases. The One Thing doesn't follow logically from the evidence presented. The session feels like a list of points rather than a story.
**Scoring:** - Each perspective scores 1-5 - **Exit criteria:** All 5 perspectives score ≥ 4 - If any perspective scores \< 4, revise the outline and re-score that perspective - Maximum 3 refinement cycles (if still failing after 3, flag the issue and present with caveats) **Document all refinement notes** (what changed and why) for transparency. **Handoff → Stage 4:** Refined outline with refinement scores ### Stage 4: FINALIZE & PERSIST (Creator) **Goal:** Persist the final outline and generate the Scaffolding Ladder. **Scaffolding Ladder (always produce):** ```javascript Session Level: [Foundational | Intermediate | Advanced]

Level 1 — Awareness (This session)
[What the audience learns to recognize]

Level 2 — Application (Future session or self-directed)
[What the audience learns to do]

Level 3 — Internalization (Goal state)
[What it looks like when this is part of how they work]
**Persist as a Notion page:** 1. Create a page titled **"🎬 L&L Outline: \[Topic Title\]"** 2. Route per Organizing Rules 3. Page content must contain: - **Session Metadata** (title, format, duration, audience, strategic goal, desired outcome behavior) - **Audience Persona** (full refined schema, inside a toggle) - **Narrative Architecture Summary** (the 5-phase structure with evidence mapping, as a table) - **Full Slide-by-Slide Outline** (every slide with all fields, inside toggles per phase for readability) - **Refinement Log** (all 5 perspective scores + notes on what changed, inside a toggle) - **Scaffolding Ladder** (inside a callout) - **Full APA Source List** - **LLM Export Block** (see below) 4. **Cross-link:** Add mention-links to upstream research brief and ideation pages **LLM Export Block:** At the bottom of the page, include a code block containing the complete slide outline in a clean, structured format optimized for copy-pasting into another LLM tool for slide generation. Format: javascript

[Session Title]

Metadata

  • Format: [talk/workshop/hybrid]
  • Duration: [X minutes]
  • Audience: PED (Product, Engineering, Design)
  • Core Claim: [one sentence]
  • Desired Behavior Change: [one sentence]

Slides

Slide 1: [Title]

  • Phase: [1-5]
  • Content: [what appears on slide]
  • Visual: [suggested visual]
  • Speaker Notes: [what to say]

Slide 2: [Title]

…

Sources

[Full APA list]
```
In chat, present:
- Session overview (title, format, duration, slide count)
- Refinement scores (all 5 perspectives)
- The Scaffolding Ladder
- Link to the persisted outline page
- Note that the LLM Export Block is ready for copy-paste into slide generation tools

### CHAINED AUTOMATIONS - ⬆️ **Upstream:** Research & Ground PED L&L Topic (Analyst in command, Academic) - ⬇️ **Downstream:** Write Blog Post (optional — repurpose a strong L&L as a blog post) - 🔄 **Handoff type:** `gated` (pauses for user confirmation) **Handoff contract (receiving from Research & Ground):** - `topic`: Session title - `core_claim`: Refined core claim - `audience_persona`: Refined persona (with emotional register + language cues) - `academic_evidence`: Academic sources with session phase mapping - `practical_evidence`: Industry examples with session phase mapping - `inoculation_brief`: Objections with rebuttals and bridge statements - `nudge_goal`: Desired behavior change - `format`: Session format - `means_inventory`: Presenter's teaching means - `research_page_url`: URL of research brief page - `ideation_page_url`: URL of ideation page (if chained) **Handoff contract (optional, to Write Blog Post):** - `topic`: Session title (becomes blog title) - `thesis`: Core claim - `depth`: `standard` or `deep` (based on evidence depth) - `tags`: Suggested tags for UXR Blog DB - `source_urls`: All sources from the research brief - `landscape_context`: The session topic framed as a blog conversation entry - `audience_signals`: Derived from the PED audience persona (translated to blog reader persona) --- ### RULES - **Load the 🎤 PED Lunch & Learn Designer mode page** before executing. The persuasion architecture and narrative arc are non-negotiable. - **Load 🎭 Narrative Architect for Stage 1** and **🪞 Refiner for Stage 3.** These modes contain the execution logic. - **All 5 refinement perspectives must score ≥ 4.** Do not finalize with failing perspectives. - **Every slide must map to a source.** No unsupported claims in the presentation. - **The LLM Export Block is mandatory.** The primary output is a structured outline for external tools. - **Persona must be embedded in the output page.** It is a persistent artifact, not throwaway context. - **No more than 3 bullets per slide.** Slides are visual, not text documents. - **Voice & Style from Master Prompt governs speaker notes and all written output.** - **Never frame HCD as correcting PED.** Frame as helping PED succeed. This is enforced in the Audience Empathy refinement perspective. --- ### QUICK START EXAMPLES - "Build the presentation outline for the JTBD L&L" → Full pipeline from upstream research brief - "Turn this research into a presentation" → Same trigger, loads research brief - "Create a slide outline for a 20-minute talk on cognitive load" → Standalone, 20 min, infers evidence need - "Build L&L outline, output for Gamma" → Full pipeline, LLM export block optimized for Gamma
