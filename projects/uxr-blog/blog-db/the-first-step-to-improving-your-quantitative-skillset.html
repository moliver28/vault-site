The first step to improving your quantitative skillset

If you ever wanted to up-level your quantitative analysis skills or become a quantitative UX Researcher but didn’t know where to start, Google Sheets Query is your answer.
It combines SQL’s power with Google Sheet’s ease of use and accessibility, letting you unlock insights from your data in minutes. By learning GS Query, your analysis workflow will be streamlined and stress-free, you’ll boost your career prospects by adding an attractive skill, and you’ll open the door to learning other programming or querying languages.
A bit of backstory first… SQL (pronounced as either “S-Q-L” or “Sequel”, but I prefer the latter) is a language used to retrieve or modify data in relational databases. GS Query is like SQL’s friendly cousin. It has many of the same functions and uses similar syntax and structure. Once you master GS Query, SQL becomes a breeze – and your resume moves up a tier.

Getting Started

For this tutorial, I’m using a modified version of the Qualtrics CSAT survey template, which includes an additional question about which product modules respondents use.
You can take the original survey here to see the layout and questions.
To get started, create a new Google Sheet with three tabs:

  • Raw Results - where you’ll paste the survey data
  • Cleaned Results- where we’ll organize the data
  • Summary - for our final analysis
    Copy the data in the Raw Results tab in this Google Sheet and paste them in your Raw Results.

Select the Columns

The most consistent way to build a query is to first select the data range to see all of the data. Then, select the columns you need and any filters on the data you want. Finally, use any summarization or aggregation functions (avg, min, max, group by, etc.) you need to get your final result.
The first query you’ll use will be in the Cleaned Results tab, and it will looks like this =QUERY('Raw Results'!A:U,,3) . The first part, (’Raw Results’!A:U), is the data range, the second is the query (which we will leave blank at first), and the last is the number of rows included in your header (three in our case).

Our final queries will be in the `Summary` tab, pulling data from our `Cleaned Results` tab. This compartmentalized approach simplifies each query which makes any troubleshooting much easier and allows for seamless integration of typical Google Sheet formulas with query results down the road. Use this same approach to create your own queries in the future. First, select the columns we need, in our case the CSAT scores in column B of the `Cleaned Results` tab. Then, show only the responses of 4 or 5. We do this using the `where` function again, followed by some logic; ```sql =QUERY('Cleaned Results'!A:D,"select B where B>=4",1) ``` If your data is text instead of numbers, your query could look like this; ```sql =QUERY('Cleaned Results'!A:D,"select B where B='Satisfied' or B='Extremely Satisfied' ",1) ``` Next, we add a `count` to that query to find the number of responses who were satisfied with their experience; ```sql =QUERY('Cleaned Results'!A:D,"select count(B) where B>=4",1) ``` Next, we need the total number of responses. The easiest way will be to add another query in the cell next to your previous one. This will be the same query but with a different condition statement; ```sql =QUERY('Cleaned Results'!A:D,"select count(B) where B is not null",1) ``` Now we can calculate the CSAT in the next empty cell by finding the percent of responses who select 4 or 5 out of the total responses. CSAT scores are great for delivering results to stakeholders. But what if you want to actually impress them? ## One Step Farther.. A common goal for stakeholders is to understand how the experience differs across various groups of users or, in our case, different product modules. In Qualtrics’ results feature, this is typically when I run into problems that cause delays. So instead, I use use a query with a `group by` function. To do this, use a new cell in the summary tab and copy the previous query that looks at respondents who selected 4 or 5 for satisfaction. Don't hesitate to reuse existing queries—whether they're from your previous work, found online, or generated by AI. Now add the product modules column to our `select` and `group by` functions. The query should look like this; ```sql =QUERY('Cleaned Results'!A:D,"select D, count(B) where B>=4 group by D",1) ``` Since we want to calculate the percentage for each product module, we need to copy the query that counts total responses and add the same `select` and `group by` statements. The query should look like this: ```sql =QUERY('Cleaned Results'!A:D,"select D, count(B) where B is not null group by D",1) ``` Now, you can add a formula to find the percent of satisfied responses out of the total responses for each product module and drag it down each row. ```notion formula =B6/D6 ``` The grouped output will look something like this; You can hide distracting columns, create charts, or add conditional formatting to guide the reader's attention and focus on the actionable insights so the data speaks for itself—all of which I will cover soon. ## Labeling Columns If you’re wondering how I made the column names easier to read in the previous queries, you can look towards the `label` function. You can add `label D 'Product Modules', count(B) 'Number of Satisfied Respondents'` to the end of the query like this; ```sql =QUERY('Cleaned Results'!A:D,"select D, count(B) where B=4 OR B=5 group by D label D 'Product Modules', count(B) 'Number of Satisfied Respondents'",1) ``` ## Pro Tip One of the benefits of this method is that you can do this using computer-generated data from Qualtrics ***before* **you actually begin collection. Extending these skills The `count` and `group by` functions are the two most powerful tools for beginning data analysts, as they can answer 70% of common stakeholder questions. You can expand your queries to include additional groups or create multiple queries in a single sheet to build live data dashboards. After mastering the `count` and `group by` functions, you can explore functions such as `avg`, `min`, `max`, and `sum` to extract deeper insights from your data—quickly enough to earn yourself a bonus nap. By following a structured approach that includes selecting columns, applying conditions, adding functions, and using standard workbook features, you will be able to build complex queries with minimal headaches.
