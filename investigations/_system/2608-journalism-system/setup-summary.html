🔧 System Architecture

User Request
    ↓
Hermes Agent (qwen3.5:397b)
    ↓
Skill Router → Loads relevant skill
    ↓
Tool Execution → web_search, browser, terminal, file, notion MCP
    ↓
Evidence Logging → Case file updated
    ↓
Notion Sync → Investigative Hub (optional)

Key Design Principles:

  1. Everything documented (chain of custody)
  2. Source reliability scored (0.0-1.0)
  3. Reproducible (another investigator could repeat)
  4. Modular skills (each has domain expertise)
  5. Notion integration for collaboration

🚨 Gaps Identified

Critical (Block Automation)

  1. No automated evidence collection — Manual prompting required
  2. No document analysis pipeline — Can extract text, not meaning
  3. No relationship mapping — No network visualization
  4. No tip/source intake — No SecureDrop equivalent
  5. No legal review workflow — No pre-publication legal check
  6. No publication pipeline — No press release/media pitching

Technical

  1. Sherlock installation fragile — Venv conflicts
  2. No image/video auto-verification — Manual triggering only
  3. No database API access — PACER, LexisNexis require paid accounts
  4. No collaboration features — Single-user only

Handoff Package Missing

  • Evidence index (searchable)
  • Source contact sheet
  • Interactive timeline
  • Document archive with OCR
  • Legal memo template
  • Publication-ready draft
  • Follow-up leads prioritized

🛠️ OSS Solutions Found

Document Analysis

  • Best: trafilatura (6.4k ⭐) — Web scraping + extraction
  • Alternative: textract (4.7k ⭐) — Text from any document
  • NLP: spaCy + HuggingFace — Named entity recognition

Claude Skills (Adaptable to Hermes)

  • claude-skills-journalism (361 ⭐) — 14 journalism skills
  • Source verification, FOIA, data journalism, fact-checking
  • Action: Adapt workflows to Hermes skills

Network Visualization

  • Best: NetworkX + Bokeh — Python, interactive
  • Alternative: Gephi — Desktop app, professional
  • Web-based: Graph Commons — Collaborative

SecureDrop Alternatives

  • SecureDrop — Official, used by NYT/WaPo (requires $2k hardware)
  • GlobaLeaks — Easier deploy, VPS-based (~$50/month)
  • OnionShare — Simplest, one-off transfers (free)

Automated Evidence Collection

  • Commercial: Hunchly ($4k/year) — Chrome extension, auto-capture
  • OSS: Playwright + ArchiveBox — DIY approach
  • Free tier: Forensic OSINT Chrome extension

OCR

  • Best: Tesseract 5 (73k ⭐) — Google-backed
  • Alternative: PaddleOCR (76k ⭐) — Better on handwriting
