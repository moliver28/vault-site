⚠️ OCR: Surya Requires llama.cpp

Problem

Surya OCR uses a VLM backend via llama.cpp. Installation failed because:

llama-server binary not found. Install with:
  macOS: brew install llama.cpp

Options

Option 1: Install llama.cpp (for Surya)

Pros: Modern OCR, 95%+ accuracy, layout-aware
Cons: Additional dependency, slower first run

Option 2: Install Tesseract (Recommended for Now)

Pros: Mature, fast, no ML backend, 87.5% accuracy
Cons: Less accurate on complex layouts than Surya/PaddleOCR

Option 3: Install PaddleOCR (Best Accuracy)

Pros: 100% accuracy on benchmarks, no external binaries
Cons: Large install (~3GB), slower than Tesseract

Option 4: Use DocumentCloud or API Services

  • DocumentCloud (free for journalists)
  • Google Cloud Vision API
  • AWS Textract

Pros: Best accuracy, no local install
Cons: Requires API key, costs money, privacy concerns
