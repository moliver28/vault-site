✅ OSS Solutions Found

1. Document Analysis Pipeline

Best Option: trafilatura (6.4k ⭐)

  • Python CLI to gather text + metadata from web
  • Crawling, scraping, extraction
  • Output: CSV, JSON, HTML, MD, TXT, XML
  • Use case: Auto-extract entities from news articles, SEC filings

Alternative: textract (4.7k ⭐)

  • “Extract text from any document. No muss. No fuss.”
  • Supports: PDF, DOCX, PPTX, XLSX, images
  • Use case: Batch document processing for case files

NLP Pipeline: spaCy + HuggingFace Transformers

  • Named Entity Recognition (NER)
  • Relation extraction
  • Sentiment analysis
  • Use case: Auto-extract names, companies, dates, amounts from filings

3. Relationship Mapping / Network Analysis

Best Option: NetworkX + Bokeh

  • Python libraries for graph analysis
  • Interactive visualizations
  • Use case: Map connections between council members, companies, donors

Example Code:

Alternative: Gephi (desktop app)

  • Professional network visualization
  • Export to HTML, PNG, PDF
  • Use case: Complex investigations with 50+ nodes

Web-based: Graph Commons

  • Collaborative network mapping
  • Free tier available
  • Use case: Multi-newsroom collaborations

4. SecureDrop Alternatives

Option 1: SecureDrop (Official)

  • Managed by Freedom of the Press Foundation
  • Used by NYT, WaPo, Guardian, 40+ outlets
  • Requirements: Dedicated hardware, Tor server, maintenance
  • Cost: ~$2k hardware + ongoing maintenance
  • Best for: Established newsrooms

Option 2: GlobaLeaks

  • Open source, easier to deploy than SecureDrop
  • Web-based whistleblowing platform
  • Requirements: VPS or dedicated server
  • Cost: ~$50/month VPS
  • Best for: Independent journalists, small newsrooms

Option 3: OnionShare

  • Simplest option
  • Share files anonymously via Tor
  • Requirements: Just install and run
  • Cost: Free
  • Best for: One-off secure transfers, not ongoing intake

Recommendation: Start with OnionShare for immediate capability, plan for GlobaLeaks deployment.

5. Automated Evidence Collection

Commercial: Hunchly ($3,995/year)

  • Chrome extension, auto-captures every page visited
  • Timestamps, hashes, full-page screenshots
  • Court-ready reports
  • Problem: Expensive, not open source

OSS Alternative: Forensic OSINT

  • Chrome extension (free tier available)
  • Auto-capture, digital signatures
  • Intelligence store for cross-case search
  • Cost: Free community tier, $99/month pro

DIY Approach: Playwright + ArchiveBox

ArchiveBox: Self-hosted web archive

  • Saves pages as PDF, screenshot, HTML, WARC
  • Scheduled captures
  • Searchable archive
  • Use case: Auto-archive all URLs mentioned in case file

6. Document Analysis with OCR

Best OSS OCR: Tesseract 5 (73k ⭐)

  • Google-backed, Apache 2.0 license
  • 100+ languages
  • Accuracy: ~95% on clean documents

Alternative: PaddleOCR (76k ⭐)

  • Baidu-backed, lighter than Tesseract
  • Better on handwritten text
  • Use case: Scanned documents, handwritten notes

DocumentCloud Add-Ons:

  • docTR — Deep learning OCR
  • OCRSpace Add-On — Example implementation
  • Use case: If using DocumentCloud for document management

7. Investigative Dashboard Platforms

Option 1: Aleph (OCCRP)

  • Investigative data platform
  • Search public records + leaks
  • Entity extraction, relationship mapping
  • Cost: Free for journalists
  • Best for: Cross-border investigations

Option 2: NINA (CLIP)

  • Latin America focused
  • AI-powered unstructured data analysis
  • Use case: Corporate registry research, conflict of interest detection

Option 3: Build Your Own with Datasette

  • Publish searchable databases
  • SQL queries, faceted search
  • Use case: Share investigation data with public
